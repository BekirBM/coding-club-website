Our Activities

Beginner Coding Workshops

Hands-on sessions where we write real code from the first minute. Each workshop covers one topic, such as variables and loops in Python or building a web page with HTML and CSS. Bring a laptop; no experience needed.

Weekend Hackathon

A 24-hour event where teams of three to four build a project from scratch around a surprise theme. Mentors are on hand to help, and the best projects win prizes.

Competitive Programming Night

We solve timed algorithm problems together, then walk through the solutions. It is great practice for coding interviews and programming contests.

Open-Source Contribution Day

Learn how to use Git and GitHub, find a beginner-friendly issue, and make your first contribution to a real open-source project. See example projects on my GitHub profile.
