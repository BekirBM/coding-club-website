# Code Crafters Coding Club Website

A simple two-page website for a student coding club, built with plain HTML5 (no CSS or JavaScript).

**Live site:** https://bekirbm.github.io/coding-club-website/

## Pages

| File | Page | Contents |
|------|------|----------|
| `index.html` | Home | Club introduction, list of club features, photo |
| `activities.html` | Activities & Registration | Four club activities, schedule table, photo, external link, registration form |

## Features

- HTML5 document structure with semantic elements: `header`, `nav`, `main`, `section`, `article`, `figure`
- Navigation menu linking both pages
- Images with descriptive alternative text
- Schedule table with a caption and column headings (Activity, Date, Time, Location)
- Registration form with:
  - Full name (text input)
  - Email (email input)
  - Preferred activity (dropdown)
  - Membership type (radio buttons)
  - Agreement to club rules (checkbox)
  - Submit button

The form does not process or save data.

## How to Run

No installation needed. Download or clone the repository and open `index.html` in any web browser:

```bash
git clone https://github.com/BekirBM/coding-club-website.git
```
